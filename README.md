# Ascend

Ascend is a full-stack job application tracker designed to help students and job seekers manage their applications, monitor interview progress, and organize their placement journey through a clean and intuitive interface.

## Features

- Secure user authentication with session-based login
- Dashboard with application statistics and recent activity
- Add, edit, search, and manage job applications
- Track application status, job type, mode, and referral source
- User profile management
- Responsive dark-themed interface

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- PHP
- MySQL

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/mahimayadav02/Ascend.git
```

2. Move the project into your local server directory.

3. Create the database using the SQL schema provided in the project.

4. Create a `backend/config/db.php` file and add your database credentials.

```php
<?php

$DB_HOST = "localhost";
$DB_NAME = "your_database_name";
$DB_USER = "root";
$DB_PASS = "";
```

5. Start your local PHP server (or Apache if using XAMPP).

6. Open the project in your browser.
